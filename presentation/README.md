# Презентация к защите

Исполнитель: Зотов Владислав Сергеевич, РПО 9/25/3. ТЗ-11/2026.

zashchita.pptx — редактируемый исходник с заметками докладчика, zashchita.pdf — версия для просмотра. 12 слайдов, запланированный доклад 7 минут. Диаграммы на слайдах редактируются. PDF собран из отрендеренных слайдов, поэтому текст в нём растровый; редактировать следует PPTX.

Это промежуточная версия от 27.10.2026. Она содержит подтверждённые сведения и явно отмечает незапущенные этапы. Перед окончательной защитой необходимо добавить фактическую заявку в leads, ManyChat, источники и воронки GA4, снимки трёх вкладок DataLens, Lighthouse и выводы по полученным данным. Не представлять этот файл как доказательство завершённых интеграций.

В титуле использованы данные исполнителя, предоставленные пользователем. На последнем слайде QR на публичный репозиторий; его адрес независимо проверен декодированием.
