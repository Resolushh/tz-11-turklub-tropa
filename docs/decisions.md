# Решения и оставшиеся зависимости

**Уточнение 29.10.2026:** Для ВК, Telegram и YouTube используются полные UTM-ссылки и проверка переходов; публикация в соцсетях и внешний сокращатель по уточнённому объёму не требуются. Поле короткой ссылки может оставаться пустым. Подтверждение источника в GA4 проверяется отдельно от корректности адреса. Упоминания недоступности vk.cc/clck.ru ниже относятся к истории проверок и больше не являются блокировкой задания.

- 27.10.2026 пользователь разрешил явно обозначенные учебные данные для вымышленного клуба. Добавлены 13 дат с местами, три инструктора с вымышленным опытом, учебная точка 60,30 и время 08:00. Километраж, набор высоты и описания достопримечательностей также обозначены учебными. Данные не являются предложением реальных поездок.
- Две партнёрские строки U-10/U-11 отложены пользователем до получения ников. Не подставлять выдуманные аккаунты.
- В разделе 5 ТЗ упомянуты пять меток. Реестр включает utm_term=winter_hiking; браузер хранит пять меток. Схема leads сохраняет четыре UTM-столбца по разделу 6.1.
- Тег G-JG7PNX1WWW установлен в head девяти HTML. Семь определений сохранены. Два лишних ключевых события сняты; системное purchase нельзя снять через доступный интерфейс Google. Нужна фиксация этого ограничения при приёмке.

- Срок хранения данных и окончательная политика требуют согласования до использования реальных персональных данных. Сейчас используются только вымышленные тестовые значения.
