# Учебные данные

Пользователь 27.10.2026 разрешил заполнить отсутствующие данные вымышленного клуба учебными примерами.

В js/config.js находятся 13 выездов на декабрь 2026 и январь 2027, включая выезд без мест и следующую доступную дату того же маршрута. Три инструктора, их имена, опыт и квалификации вымышлены. Точка сбора 60.0000, 30.0000 и время 08:00 используются только для демонстрации карты. Реальные поездки не продаются.

На страницах эти данные явно обозначены учебными. Число мест является демонстрационным массивом, а не остатками из системы бронирования. Для реального клуба нужен серверный учёт и согласованные сведения.
