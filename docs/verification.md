# Проверка начальной версии

Дата: 27.10.2026.

- Синтаксис JS: node --check для analytics.js, site.js, form.js — успешно.
- Браузер: фильтр «легко» показывает 3 маршрута.
- Калькулятор: спальник + коврик, 2 суток = 1300 ₽.
- Пустая форма: показывает ошибки имени, телефона, даты и согласий; выбранный маршрут сохраняется из URL.
- Все 9 страниц проверены на 375, 768, 1280 px. Найден перенос длинного заголовка политики на 375 px, исправлен через overflow-wrap; повторная проверка проводится после изменения.
- Apps Script проверен в Node vm с имитацией Google API: успешная запись; отсутствие дубля request_id; status из браузера игнорируется; 12 некорректных наборов данных отклонены; защита от формул; значения источника по умолчанию. Это не проверка подключения к Google.
- PDF-чек-лист отрендерен Poppler, проверен визуально.

Не проверены: Lighthouse, реальные GA4 и DebugView, передача fetch в Apps Script, Vercel, публикации, ManyChat, DataLens. Сайт пока не соответствует всем условиям приёмки.
