# Оформление и движение — 29.10.2026

Добавлены закреплённая полупрозрачная шапка с тенью при прокрутке, тонкий индикатор чтения, кнопка возврата к началу с возвратом фокуса, анимация первого экрана и однократное появление блоков при прокрутке. Карточки поднимаются, фотографии слегка приближаются при наведении точного указателя. Улучшены состояния фокуса, нажатия, полей ввода и раскрытого мобильного меню. Escape закрывает меню и возвращает фокус кнопке.

Без библиотек анимации и непрерывных фоновых эффектов. IntersectionObserver запускает короткие transform/opacity-анимации Web Animations API; исходный контент остаётся видимым без этих API. prefers-reduced-motion отключает эффекты, включая уже запущенные при изменении настройки. Проверка этой ветки проведена по коду; настройка ОС в этом проходе не переключалась.

Убрана загрузка больше не используемого Russo One. CSS и site.js получили версию в URL, чтобы обновление не зависело от старого кэша. Обработчик отправки формы, конфигурация GA4 и аналитика не изменялись.

Проверено в браузере: 9 страниц × 375/1280 px, без горизонтального переполнения и битых img. Скрипт улучшений работает на всех 18 проверках.
