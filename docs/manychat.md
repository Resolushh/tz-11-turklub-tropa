Профессиональный Instagram должен принадлежать учебному проекту. Личная страница для публикаций по ТЗ не используется. Автоматизация: `IG · Winter Trips 2026 · Tent Reel`. Триггер — комментарий к конкретному Reel «Ночёвка в палатке при −15 °C», а не ко всем публикациям.

## Ветка СНАРЯГА

Ключевое слово: `СНАРЯГА`.

Три случайных варианта публичного ответа:

- Отправили чек-лист в личные сообщения 🏔
- Проверь директ — там список снаряжения
- Готово! Чек-лист и промокод уже в сообщениях

Сообщение в Direct: «Привет! Это „Тропа“. Держи чек-лист „Что взять в зимний поход“ и калькулятор аренды — если чего-то нет, дадим.»

Сообщение в Direct: «Три зимних маршрута, которые проходят без опыта, — по кнопке ниже.»

Кнопка «Маршруты для новичков» (U-03):

Якорь находится после UTM. На сайте #easy включает фильтр «легко»: Ледяные водопады, Снегоступы для начинающих, Новогодняя изба.

## Проверка после подключения

1. Выбрать конкретный опубликованный Reel, настроить обе ветки и включить Live.
2. Со второго аккаунта оставить каждый комментарий. Между повторными проверками выдерживать минимум две минуты.
3. Подтвердить публичный ответ и Direct (в том числе папку «Запросы»).
4. Перейти по кнопке; сохранить кадр полного адреса с UTM.
5. После запуска приёмника отправить учебную заявку; сверить UTM в leads и generate_lead в GA4.
6. Сохранить фактические кадры в screens/instagram/. Пока этих доказательств нет.
